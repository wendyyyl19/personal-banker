# personal-banker


Here is my personal banker project.

The purpose of this project is to help me record my money expense. As an international student, I struggle a lot in recording my money. Here are the reasons:
1. Being in a new environment, it is hard to pay attention to my money expense without a proper system
2. There is exchange rate between the money I used here and RMB. I need to calculate that often.
3. I used to track things in a paper but I always lost it.

I will record my coding joruney here so that I can use this personal banker to track my money, summarize in categories easily and calculate into RMB with ease.
